# STEP 2 v0.2.13 — スキルストック分布・編成離脱時の所持状態監査

日付：2026-10-17。**STEP 2の週間計算精度ゲートはHOLD。STEP 3には進まない。**

## 原因と修正
- 従来は `min(期待成功回数,ストック上限)` で、有限回の抽選からの `E[min(成功回数,上限)]` を過大評価していた。
- `advanceSkillStock` によりストック上限1（一般）／2（スキル・All専門）の確率分布をおてつだいごとに遷移させる。回収まで状態を保持し、回収時に発動期待回数を計算してストックをクリアする。
- 15分刻みの小数おてつだいは端数のベルヌーイ発生として近似。発動確率は既存のピティ補正済み長期平均を使用し、ゲーム内の実際の連続不発カウント・発動時刻・相関はまだ再現できない。
- 別メンバーに入れ替えたとき、離脱個体の未回収の通常所持品・別枠999所持品を消去。従来のたくわえる蓄積リセット、現在残留している個体の持ち物は維持。
- ユーザー指定で完全除外の7スキル、固定睡眠パーティ、0:00–7:30放置、月曜4:00非回収、料理・げんき回復の既存仕様は維持。

## 計算例
成功確率50%、おてつだい2回、ストック上限1：0回0.25／1回0.75、期待値0.75（旧方式では1.00）。
成功確率50%、おてつだい2回、ストック上限2：0回0.25／1回0.50／2回0.25、期待値1.00。
