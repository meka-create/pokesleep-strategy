1. ボックスタブで睡眠パーティを5匹揃えた直後、試算タブの `runSim` を有効化／4匹に戻した際に無効化する判定を同時更新。変更前は `renderBox()` 内の操作が `updateRosterStatus()` を呼ばず、睡眠5匹を揃えても「20枠未完成」のままの可能性があった（実用上の操作不能、P1）。
2. 直前に算出した週間結果が見えている状態でフィールド・回収・鍋・バッグ・料理設定、昼間のロスター、睡眠5匹、保存したイベント設定を変更した場合、「**変更前の条件で計算した結果**」という警告を表示。再試算成功時にクリア。古い実測用の `lastRunSnapshot` は勝手に現在の条件で上書きしない（計算結果の取り違え防止、P1）。
3. 朝昼夜のプルダウンで重複個体を選んで拒否されたとき、描画直後の古い5匹へ戻すのではなく、**直前の保存済み有効編成の同じ枠**へ戻す。複数回の有効な入替後に重複を選んだ場合に、画面だけ重複編成になって試算不能になる実用不具合を防止（P1）。
4. 週切替（月曜04:00）、睡眠0:00～7:30固定、7:30初回回収、きのみ・食材・スキルの主計算は変更しない。実ゲームの確率値や未取得の数値を埋める変更は行わない。

**確認範囲で新規の確証あるP0（実測と照合済みの重大計算式誤り）は未発見。** すべての入力・抽選分岐にP0が存在しないという保証ではない。料理成立、2ヒーラー、多重スキルストック、発動時刻相関、バッグ連続分岐の残る不確実性は条件付き結果・警告・比較保留として扱う。
