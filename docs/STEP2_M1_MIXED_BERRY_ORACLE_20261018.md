# STEP 2 M1 — 異種混成・編成交代の独立1分時計算（2026-10-18）

対象：`scripts/step2-m1-mixed-berry-oracle.cjs`、`tests/step2-m1-mixed-berry-oracle.test.cjs`。

**実装範囲：** 既存の14条件＋5組のM1ベースラインは固定したまま、追加の制御条件MB01・MB02を検証する。**STEP2精度ゲートHOLD、M1 PARTIAL、STEP3未着手**。

## なぜこれを先に行うか

既存D04/D05は同じライチュウ5匹の1分計算と週間モデルを比較していた。異なる種族・おてつだい頻度・きのみ種類・日中の朝昼夜交代では、ポケットの回収処理、げんき減少タイマー、おてつだい途中の進捗破棄が複雑化する。その不整合を完全な食材・スキル抽選の前に独立計算で確認する。

## 比較条件（人工制御のB級）

- **7種**：ライチュウ、フシギバナ、リザードン、プクリン、バクフーン、トドゼルガ、エーフィ。いずれもLv1／まじめ／サブスキルなし／リボンなし。
- 種族のきのみ・基礎速度・得意タイプはマスターから取得。きのみ単位エナジーとげんき速度境界は、本体の関数を使わずに別式で計算。
- **食材確率・メインスキル確率を0、所持上限を十分大きくする（人工条件）**。これらの変更値は計算直後に必ず復元する。実在の7種の週間期待値や確率精度を示すものではない。
- 好み：ゴールド旧発電所。FB25%。いいキャンプOFF、料理未選択、きのみ分のみ計上、睡眠0:00〜7:30の5匹固定、翌月曜04:00に架空回収を置かない。
- **MB01**：5匹固定、開始げんき100、睡眠スコア0。
- **MB02**：朝の5匹→昼は2匹交代→夜は1匹交代、睡眠5匹は固定。開始げんき30、睡眠スコア80。
- 参照実装は毎分の仕事進捗を積算し、10分ごとにげんきを減らす。交代時に離脱者のおてつだい進捗・げんき減少タイマーを破棄、帰還時には停止状態から再開。6回の朝の睡眠回復で増加時だけタイマーをリセットする。7日目の未回収睡眠4時間は**今週に加算しない**。
- 1種類ずつの成功エナジーではなく、7種の**完了おてつだい回数×1回きのみ個数×独立きのみ強さ**を加算して、週間計算本体のきのみ・合計と数値比較。

## 証拠の境界

**B級の独立参照式**として検証できるのは、与えた人工条件における**きのみ・曜日・編成交代・げんき時計の算術**。ゲームの現実のメインスキル、食材バッグ、料理成立、ランダムげんき回復と相関は検証していない。

本テストの成功は既存のM01〜M04の外部週間エナジー実測、R01〜R05の編成順位の実測が揃ったことを意味しない。最初の14条件内の9/9独立照合＋5未検証という記録は維持する。

## 次に必要なもの

1. M01〜M04の食材・スキルを有効にした混成7日間について、再現可能な外部参照または同条件の複数ゲーム実測。
2. R01〜R05の相対順位について、誤差やランダムばらつきを考慮した独立比較。
3. 検出されたP0に優先順位を付けた修正と再計算。M1不完了のままSTEP2を合格させない。
