# W3 v0.5.0 — 週間28枠UI実装・受入ゲート（2026-10-27）

## 実装範囲

- 試算タブの「週間28枠の編成計画」に、月～日×朝／昼／夜／睡眠の7行×4枠を一覧表示する。
- 各曜日・時間帯の5匹は、1枠ずつ選んで編集し、**該当曜日・時間帯だけ**保存する。日中21枠の既存基本3枠からの一括設定を用意する。
- **睡眠自動提案は初期OFF**。OFFでは基本睡眠5匹を全7晩へ一括設定し、必要な晩だけ1匹ずつ変更できる。前夜からのコピーも可能。
- ONではW2による睡眠7晩も探索対象にする。ON/OFFの切替だけで手動の睡眠7晩は上書きしない。
- W2の有界探索は12回以内。1回ごとのW1週間試算・進捗表示、固定案との週間総エナジー比較、7日×4枠プレビューを備え、明示的な適用まで計画を変更しない。
- 日中基本3枠がまだ未設定でも、ボックスの睡眠5匹が揃っていれば自動候補探索を開始できる。
- 日別手動・自動計画を通常の7日試算と観測JSONに受け渡す。JSON version:1、16列CSVの互換を維持。
- 観測JSONに曜日別28枠が含まれる場合は各枠の5個体IDを厳格に検証。旧固定チームの対照比較へ変動編成を混入させない。
