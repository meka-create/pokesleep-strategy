# W1 週間28枠シミュレーター — 実装記録（2026-10-27）

## 対象と位置付け

W1では日中7日×朝昼夜＝21枠、および月曜夜～日曜夜の睡眠7枠を入力可能な連続週間計算器を実装した。週間自動探索（W2）や画面からの手動編集・全7晩一括適用（W3）を完成したとは扱わない。

## 公開したコードAPI

- PokeSimulator.simulate は teamsByDay[0..6] （各 {morning,noon,evening}・各5匹）と sleepTeamsByDay[0..6] （各5匹）を任意で受け付ける。
- どちらも省略した場合は従来の teams.morning/noon/evening/sleep を7日反復し、旧週間出力を維持する。
- 曜日配列を渡した場合は7日すべてを要求し、欠落・重複・未登録個体を拒否。計算中はげんき・料理・食材・スキル・所持の状態を連続して保持する。
- 日曜夜の計算は翌月曜04:00で終了。0:00～7:30の無操作原則は維持し、曜日別睡眠編成について実際の就寝前切替時刻との差は警告する。

## 旧保存データの互換と安全性

- 既存のJSON version:1、16列CSVを維持。
- optional weeklyPlan を追加。dayTeams、manualSleepTeams、autoSleepTeams、sleepAuto（初期OFF）を検証し、手動7晩と自動7晩を独立して保存する。
- 旧バックアップでweeklyPlanが未記録なら、旧3枠と既存の睡眠5匹をそれぞれ7日へ展開する。
- PokeStorage.resolveWeeklyPlan が計算用の日中・睡眠7回を返す。ONで自動睡眠案が未作成なら拒否する。
- CSV再取り込み時は曜日別すべての保存IDを照合。完全に安全な対応が作れない週次計画は取り消し、再設定の必要性を表示する。

## 検証項目

- 従来の固定3枠＋固定睡眠5匹 vs 全曜日同一28枠の出力一致。
- ある曜日だけ異なる日中5匹、および火曜夜に異なる睡眠5匹を置いた際の水曜の回復・エナジー変化。
- 7日分不足、5匹不足、重複、未登録個体を拒否。
- 旧JSON復元、睡眠手動7晩の個別変更保存、ON未作成拒否、CSV再取り込み時のID引継ぎ・不確定時の無効化。
