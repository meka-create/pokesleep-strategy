# M2 料理チャンスの大成功後リセット履歴（v0.2.62 / 2026-10-22）

## 不具合の再現

旧式では料理直後のボーナス分布を平均ボーナス1値へ潰し、次の料理で再び成功率を計算していた。大成功後に蓄積ボーナスが0へ戻る枝と、失敗して維持される枝を区別しないため、3食目以降を過大計上しうる。

人工入力：初期蓄積0.7、通常基礎確率0.1、追加スキル加算なしの3食。
独立全分岐：0.8、0.24、0.128。旧平均式：3食目0.2064。差0.0784（7.84ポイント）。

これは確率計算の人工検算であり、実ゲームのスキル抽選率・期待エナジーの精度を検証したものではない。

## 修正

`src/simulator.js`で（ボーナス, 確率質量）のMapを保持し、各料理の成功枝は0へリセット、失敗枝は蓄積ボーナスを維持。新規ボーナスは各枝へ加算し上限0.7を適用。日曜は基礎確率0.3、通常0.1。不成立料理ではリセットしない。大成功期待値OFFは従来どおり。料理チャンスS／ビルドアップに接続し、外部`successBonus`は互換の期待値として出力する。

**限定事項**：スキル加算量はなお発動回数の期待値で、実発動履歴の確率分布・上限ストック・料理状態との相関は未解決。対象スキルがチームに存在する場合の警告および週間観測の比較HOLDは維持し、ボックス内の未選択個体だけでは警告しない。
