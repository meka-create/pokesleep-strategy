# STEP 2 — 回復スキル「げんきエールS」の対象抽選比率修正（2026-10-18）

## 監査の背景と範囲

R02（ヒーラー1匹／2匹）のモデル順位に大きな感度があるため、週間エンジンのげんき回復処理を**別の計算器の実コード**と照合した。現行R02のプクリン・サーナイトが使う「げんきオールS」の効果量は `pokesleep-tool` のレベル別 `[5,7,9,11,15,18]` と一致しており、こちらは変更しない。

一方、通常「げんきエールS」（及び同系列の「ほっぺすりすり」）の受取対象選択に以下の**参照実装との差異**が見つかった。

| 条件 | 修正前の週間エンジン | `pokesleep-tool`（外部コード） | 修正後 |
|---|---:|---:|---:|
| 最低げんきの全個体間で均等抽選する分岐 | 70% | 65% | **65%** |
| チーム全体から均等抽選する分岐 | 30% | 35% | **35%** |
| 最低げんきが同率の対象判定 | `minimum+1e-9` まで同率 | 厳密に最低値と等しいときのみ | **厳密一致** |

外部基準：`nitoyon/pokesleep-tool` の [EnergizingCheer.ts](https://github.com/nitoyon/pokesleep-tool/blob/0ab2e81621d0a60b358e357890145b150ae1e1d2/src/util/Team/Skill/EnergizingCheer.ts) および [EnergizingCheer.test.ts](https://github.com/nitoyon/pokesleep-tool/blob/0ab2e81621d0a60b358e357890145b150ae1e1d2/src/util/Team/Skill/EnergizingCheer.test.ts)（照合時main SHA `0ab2e81621d0a60b358e357890145b150ae1e1d2`）。元のスキルLv別効果：[MainSkill.ts](https://github.com/nitoyon/pokesleep-tool/blob/0ab2e81621d0a60b358e357890145b150ae1e1d2/src/util/MainSkill.ts)。

**独立性：** これは外部の独立実装との仕様不一致というB級の監査根拠。65%がゲーム内部で直接観測された真の確率であるというA級の主張ではない。スキルの発動時刻、げんき上限との同時相関や週間実測は引き続き未検証。

## 数学的な回帰参照

5匹の期待対象確率は、最低げんき同率の人数を `k` とすると

`P(i)=0.35/5 + 0.65/k` （`i` が厳密最低値のとき）。その他は `0.35/5`。

- 1匹だけ最低：対象最低は `0.72`、それ以外の4匹は各 `0.07`（旧 `0.76` と `0.06`）。
- 2匹が同率最低：2匹は各 `0.395`、それ以外は各 `0.07`（旧 `0.41` と `0.06`）。
- 5匹全員同率：全員 `0.20`（修正前後で一致）。
- ごくわずかに上のげんき値は、最低値と**同率扱いしない**。

`tests/simulator.test.cjs` に期待値分布・合計確率1・厳密同率の境界テストを追加。これにより、将来の数式修正で元の70%仮定に戻る先祖返りを防止する。

- **M2/P1の限定修正**。参照実装との確認された差異を解消するが、げんきエールの対象選択率のゲーム実測・独立週間エネルギー校正ではない。
- R02はこのスキルを使わないため、**R02順位問題の解消に数えない**。R01〜R05の凍結ベンチマーク、M1の10/14限定B照合・混成4未検証、5組の実ゲーム順位未検証を維持する。
