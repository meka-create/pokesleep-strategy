# STEP 2 メインスキル計算対象の確定範囲

更新：2026-10-16（ユーザー指定）

## 基本方針
ポケスリ作戦室では、現行種族マスターに登場するメインスキル**36種類**のうち、**7種類はユーザーの指定により完全に計算対象外**とする。残り**29種類**を今後の計算対象とする。

### 計算対象から除外する7種類
| ゲーム表示名 | マスターの内部識別子 |
|---|---|
| ゆびをふる | `Metronome` |
| ものまね（スキルコピー） | `Skill Copy (Mimic)` |
| へんしん（スキルコピー） | `Skill Copy (Transform)` |
| オールマイティー | `Versatile` |
| ゆめのかけらゲットS | `Dream Shard Magnet S` |
| ゆめのかけらゲットS（ランダム） | `Dream Shard Magnet S (Random)` |
| はどうだん（ゆめのかけらゲットS） | `Dream Shard Magnet S (Aura Sphere)` |

- メインスキルのエナジー、げんき、食材、追加おてつだい、コピー・抽選、ゆめのかけら等の効果は、**すべて計算しない**。はどうだんに含まれる直接エナジーも除外。
- これらを持つポケモンの**通常のおてつだい、きのみ、食材の獲得およびサブスキルの作用**は引き続き計算する。
- 除外対象は「実装漏れ／未対応スキル」とは区別し、STEP 2の精度監査の必須実装数には含めない。利用者が試算で該当個体を選んだ場合は、意図的な除外を結果の注意欄に表示する。
- 将来のSTEP 3自動編成でも、指定された7種類による寄与を評価に加算しない。対象ポケモン自体を候補から禁止するわけではない。ユーザーの新しい指示がない限り、この仕様を維持する。

### 最新実装との区別（2026-10-20・v0.2.53。スキル計算対象範囲は変更なし）

以下のv0.2.8一覧は**当時の29種類の実装範囲を記録した履歴**であり、最新の計算式ではない。ユーザー指定の除外7種類は変わらない。v0.2.31ではげんきエール系の対象重みを上流の「最低げんき65%＋均等35%」に合わせ、v0.2.50では「いやしのはどう」の1発動について、同じ重みで1匹目を抽選・回復し、その個体を除く4匹から回復後のげんきを反映して2匹目を選ぶ5×4の順次分岐に変更した。**週内の発動履歴・げんき・所持品の結合は未検証**。

v0.2.51では「みかづきのいのり」を、他の全員回復スキルと同時に日中編成した際の**順位未検証警告**へ追加した。これは警告判定だけの変更であり、回復量や週間順位の正確性を確認したものではない。詳細は[STEP2_STATUS](STEP2_STATUS.md)、[いやしのはどう参照監査](STEP2_M2_HEAL_PULSE_RECIPIENT_REFERENCE_20261020.md)を参照。**STEP2精度HOLD／STEP3未着手**。

### v0.2.8 時点の29種類（暫定・部分対応）
現行マスター36種類のうち、**29種類について基本効果の暫定計算経路が存在**する。ゲーム内の完全再現・絶対精度の監査合格とは異なる。

- **直接エナジー：5種類** — エナジーチャージS／同ランダム／M／ナイトメア／たくわえる
- **げんき回復：7種類** — げんきチャージS／げんきオールS／げんきエールS／ほっぺすりすり／つきのひかり／きのみジュース／いやしのはどう
- **料理・食材：9種類** — 食材ゲットS／プラス／プレゼント、料理パワーアップS／マイナス、料理チャンスS、食材セレクトS／きょううん／かいりきバサミ
- **追加おてつだい：2種類** — おてつだいサポートS／おてつだいブースト
- **複合（食材＋料理）：1種類** — ビルドアップ
- **きのみ・複合：5種類** — きのみバースト／ばけのかわ／りゅうせいぐん／サイコブレイク／みかづきのいのり

合計：5＋7＋9＋2＋1＋5＝**29種類**。ユーザー指定の7種類は引き続き全効果除外（対象個体の通常のおてつだいは計上）。

#### v0.2.8当時の精度上の未完了項目（変更後の仕様は上記およびSTATUS参照）
- **たくわえる**：v0.2.9で有限7日間の確率状態、交代リセット、週末未放出の非加算を実装。75%蓄積／25%放出は推定値であり、正確な抽選時刻とゲーム実測は未確認。
- **サイコブレイク**：直接エナジーのみ。マゴのみの継続強化、上限、ゾーン期間は未実装。
- **いやしのはどう（当時）**：対象2匹への基本回復・追加おてつだい、ラティアス／ラティオス同時編成での追加回数を均等期待値で計算していた。**v0.2.50で対象抽選を順次分岐へ修正済み**。収集時刻・週間相関は未検証。
- **おてつだいサポート／ブースト**：追加生産の基本期待値は計算するが、その追加おてつだいからのスキル発動は発生させず、対象抽選・別枠999個の所持・回収は期待値近似。
- **げんきエール系（当時）**：低げんき優先確率を仮定で扱っていた。**v0.2.31以降は上流参照の65%／35%に一致**させているが、独立した実ゲーム抽選率の計測ではない。
- **食材系・料理スキル**：条件付きの追加効果、発見済み食材の正確な抽選、実際の料理タイミング等は部分未対応。
- **りゅうせいぐん／みかづきのいのり**：元のきのみ個数表を反映するが、発動の蓄積状態や小数丸めは簡易計算。
- **その他のスキル**：ポケモンごとの実スキルストックや発動抽選、週またぎの所持品等は共通の近似モデル。

そのため**29種類が計算経路に載ったことのみをもって、STEP 2精度ゲート合格／STEP 3開始の根拠としない**。詳細： [v0.2.8精度監査記録](STEP2_V028_SKILL_AUDIT.md)。

## 動作・回帰テスト
- `src/simulator.js` の `EXCLUDED_MAIN_SKILLS` を唯一の除外判定の根拠にする。
- `tests/simulator.test.cjs` で7種類すべてを個別に試験：スキルエナジー0、スキル発動集計0、通常きのみ獲得は維持、未対応警告と区別する。
- オールマイティーについては、個体の`mainSkill`にエナジーチャージMが入っていてもコピー／転用して計算しない。
- 通常のエナジーチャージは継続してスキルエナジーを計上することも回帰試験する。

注記：除外以外の29種類についても、正確な全効果を再現できたわけではない。スキル発動期待値やげんき推移などの精度ゲートは引き続き保留する。
