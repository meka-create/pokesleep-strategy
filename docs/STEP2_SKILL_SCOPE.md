# STEP 2 メインスキル計算対象の確定範囲

更新：2026-10-16（ユーザー指定）

## 基本方針
ポケスリ作戦室では、現行種族マスターに登場するメインスキル**36種類**のうち、**7種類はユーザーの指定により完全に計算対象外**とする。残り**29種類**を今後の計算対象とする。

### 計算対象から除外する7種類
| ゲーム表示名 | マスターの内部識別子 |
|---|---|
| ゆびをふる | `Metronome` |
| ものまね（スキルコピー） | `Skill Copy (Mimic)` |
| へんしん（スキルコピー） | `Skill Copy (Transform)` |
| オールマイティー | `Versatile` |
| ゆめのかけらゲットS | `Dream Shard Magnet S` |
| ゆめのかけらゲットS（ランダム） | `Dream Shard Magnet S (Random)` |
| はどうだん（ゆめのかけらゲットS） | `Dream Shard Magnet S (Aura Sphere)` |

- メインスキルのエナジー、げんき、食材、追加おてつだい、コピー・抽選、ゆめのかけら等の効果は、**すべて計算しない**。はどうだんに含まれる直接エナジーも除外。
- これらを持つポケモンの**通常のおてつだい、きのみ、食材の獲得およびサブスキルの作用**は引き続き計算する。
- 除外対象は「実装漏れ／未対応スキル」とは区別し、STEP 2の精度監査の必須実装数には含めない。利用者が試算で該当個体を選んだ場合は、意図的な除外を結果の注意欄に表示する。
- 将来のSTEP 3自動編成でも、指定された7種類による寄与を評価に加算しない。対象ポケモン自体を候補から禁止するわけではない。ユーザーの新しい指示がない限り、この仕様を維持する。

### 継続実装する29種類
現行 v0.2.7 時点で基本効果を**暫定・部分計算済み22種類**：
- 従来の5種類：エナジーチャージS、エナジーチャージS（ランダム）、エナジーチャージM、げんきチャージS、げんきオールS。
- **v0.2.5で部分対応を追加した5種類**：食材ゲットS、プレゼント（食材ゲットS）、プラス（食材ゲットS）、料理パワーアップS、マイナス（料理パワーアップS）。

v0.2.5の注意：食材ゲット系はユーザーが発見済み食材を設定した場合のみ、その候補への均等配分として材料に計上します。未設定の場合は「未配分の期待食材数」を報告し料理には加算しません。プラスの条件付き追加食材、マイナスの条件付きげんき回復、プレゼントのアメは計算対象の完全実装ではありません。料理パワーアップ系は鍋容量の基本効果（次回料理まで累積・上限＋200）のみ対応。追加食材を任意投入する仕組みは未完成です。**実装済み10種類も精度ゲートは未合格**です。

**v0.2.7で部分対応を追加した12種類**：
- きのみバースト、ばけのかわ
- げんきエールS、ほっぺすりすり
- 食材セレクトS、きょううん、かいりきバサミ
- ビルドアップ、料理チャンスS
- ナイトメア、つきのひかり、きのみジュース

**追加実装の対象7種類**（以下は引き続き未対応）：
- おてつだいサポートS（Extra Helpful S）
- おてつだいブースト（Helper Boost）
- りゅうせいぐん（Berry Burst (Draco Meteor)）
- サイコブレイク（Berry Zone (Psystrike)）
- いやしのはどう（Energizing Cheer S (Heal Pulse)）
- みかづきのいのり（Energy for Everyone S (Lunar Blessing)）
- たくわえる（Charge Strength S (Stockpile)）

**過去の分類ごとの未対応件数メモ（19種類）は上記7種類へ更新済み。** いずれも現行マスターに登場するスキルの名前であり、実際の複合効果は別途検証する。

### 参考用：旧分類（非最新）

- 食材セレクト系3種類
- 料理チャンス・料理アシスト系2種類
- げんきエールおよびげんきチャージ／げんきオールの特殊派生6種類
- おてつだいサポート・おてつだいブースト系2種類
- きのみバースト・きのみゾーン系4種類
- たくわえる・ナイトメア系2種類

合計：22（暫定・部分対応）＋7（追加予定）＋7（明示除外）＝**36種類**。

## 動作・回帰テスト
- `src/simulator.js` の `EXCLUDED_MAIN_SKILLS` を唯一の除外判定の根拠にする。
- `tests/simulator.test.cjs` で7種類すべてを個別に試験：スキルエナジー0、スキル発動集計0、通常きのみ獲得は維持、未対応警告と区別する。
- オールマイティーについては、個体の`mainSkill`にエナジーチャージMが入っていてもコピー／転用して計算しない。
- 通常のエナジーチャージは継続してスキルエナジーを計上することも回帰試験する。

注記：除外以外の29種類についても、正確な全効果を再現できたわけではない。スキル発動期待値やげんき推移などの精度ゲートは引き続き保留する。
