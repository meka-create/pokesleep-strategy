# STEP 1 開発結果・監査待ち

## 実装できたもの
1. 16列CSV/TSVヘッダー照合、BOM/CRLF、セル内のカンマ・ダブルクォート・改行、異常時の全件ロールバック。
2. 同名個体も個別保持するボックス一覧と検索。
3. 育成用睡眠パーティ最大5匹（選択、解除、保存）。
4. 1/2週イベント入力、料理4モード、フィールド自由選択、イベント補正メモ、準備週・各イベント週のいいキャンプチケット。
5. ブラウザ保存、JSONバックアップ／復元、全削除。
6. 依存のない単一HTML配布版（ルートの `index.html`）と開発用ソース。

## 確認
- Node標準テスト 8件PASS（CSV/TSV、引用符、同名個体、異常ファイル、安全なバックアップ）。
- Chromiumのモバイル幅393pxで入力／7匹のCSV読み込み／睡眠5匹上限／保存復帰／壊れたCSVでの保持：PASS、JS例外なし。
- **実ブラウザのHTTP/Fileナビゲーションが実行環境で管理者ブロックされたため、DOMテストはabout:blankへ実HTMLを書き込む方法で実施**。Android実機E2Eではない。

## 未完了・制約
- GitHubの接続ツールには「非公開リポジトリ新規作成」操作がない。ユーザーの既存リポジトリはいずれも公開状態だったため、勝手なアップロードは行わなかった。ユーザーが空の非公開リポジトリを作成すれば、そのリポジトリへソースを追加できる。
- 認証付きWebプレビューは未設置。配布したHTMLはローカルで操作できるが、AndroidのファイルURLでlocalStorageが使えるかは実機次第。必ずJSONバックアップを使う。
- 実際のユーザーCSVによる互換性試験は未実施。STEP1監査時にユーザーのCSVで確認するのが望ましい。
- ゲーム計算・料理マスター・自動編成等は未実装（ロードマップ通り）。
