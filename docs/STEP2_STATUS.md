- 朝7:30-12:00、昼12:00-18:00、夜18:00-0:00、睡眠0:00-7:30の各5匹を手動指定。
- 15分刻みの期待値近似で、おてつだい数、きのみ、食材、所持数、いつのまに育成の一部、スキルストックを試算。
- `src/util/Berry.ts` のきのみエナジー基礎式、`src/util/Energy.ts` のげんき帯による速度係数、`src/util/Nature.ts` の性格補正、`src/util/MainSkill.ts` の直接エナジー・回復値表を参考。

- フィールドボーナス、固定マップの好みのきのみ、2-3時間回収、鍋容量、開始時の一律げんき、睡眠スコア、キャンプチケットON/OFF。
- 睡眠中の無操作、睡眠パーティのエナジー計上、ボックス内ポケモンへの通常5%回復を付与しないこと。
- 集計はゲーム週に合わせ、月曜7:30開始〜翌月曜4:00終了。月曜4:00-7:30はフィールド未移動につき計上しない。
- 選択した3パーティ・計算設定はSTEP1の保存・バックアップに追加し、以前のv1保存データも読み込める。
- 自動編成はSTEP3。食材逆算と全料理マスターはSTEP4以降、ランダム条件/イベント効果・2週間計算はSTEP5。

## 計算の制約（UIでも必ず表示）
これは**暫定的な期待値モデル**。ゲーム内エナジーと厳密に一致することを保証しない。最終的なパーティ選択の根拠として使う前に未対応事項を解消する。
- 個体の開始げんきを一律値で仮定。スキルの発動は期待値で扱い、ゲーム内のスキル天井・ピティ・発動時刻は簡略化。
- 食材の所持上限超過は概算し、夜間のいつのまに育成を単純化。スキルによる食材・鍋増加・おてつだい補助等は未計上と明示。
- エナジーチャージS/MとげんきオールS、自分のげんき回復S以外のスキル効果は一部未対応。
- 料理レシピはv0.2.3で78品に拡充済み。ただしv0.2.6で毎食の局所自動選択は部分対応、週間全体の最適化は未対応、Lv70・大成功なし・追加食材なし。全レシピと大成功は今後拡張。現在の初期在庫は19種類に対応し、バッグ容量の近似上限を追加済み。
- イベント固有効果・EXの特殊効果は未計上。マップによってきのみがランダムな場合、きのみボーナスを適用せず警告。
- 初期所持数を実際に入力できないので、月曜7:30のポケモン所持数は0、初期げんきのみユーザー共通設定。前週からの所持数/スキルストック引継ぎは非対応。
- ポケモンレベル、スキル、補正などの一部で近似を使用しているため、結果の確からしさは未評価。今後の監査で優先的に見直す。
