## 比較条件

- `scripts/step2-m1-five-ranking-sensitivity.cjs` が、既存M1のR01〜R05を**同じ10個体・6種類の日中編成**で再現する。全組で睡眠チームはライチュウ5匹固定、Lv50・まじめ・サブスキルなし。睡眠スコア88、フィールドボーナス25%、朝昼夜の時間帯や回収、7日間の他条件は固定。
- プクリン・サーナイトのメインスキル抽選率のみ**0.75倍と1倍**で比較。各モードで6編成×2倍率の週間計算を行い、5組のB−A差とモデル上の優劣を比較する。マスターの一時変更は `finally` で元に戻す。
- **original-140**：v0.2.30の元の食材140個に一致。倍率1で**5組すべて**の凍結基準値・内訳と一致することを自動検証。
- **guaranteed-147**：21食すべてを初期の確定リンゴだけで賄えるようにする。これでもモデル内の順位感度が現れるか比較する。
- 全体の内部感度とは別に、R01〜R05の真のゲーム順位は外部参照がないため**全てUNVERIFIED_RANKINGのまま**。

## 判定基準

倍率0.75→1で優位が入れ替わった組は「P1：スキルイベントの独立照合を優先」、入れ替わらない組も**ゲーム上の順位が正しいという証明はない**。この2倍率での非逆転を「安定性検証PASS」や誤差率の下限・上限と見なしてはいけない。

`npm run m1:five-ranking-sensitivity` は2条件×2倍率×6編成のモデル値・5組の比較・優先調査対象をJSON出力。**A級実ゲーム証拠なし／M1 PARTIAL／STEP2 HOLD／STEP3未着手**。
