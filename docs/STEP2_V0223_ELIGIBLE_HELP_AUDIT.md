# STEP 2 v0.2.23 — 所持枠×抽選可能回数の区間内結合監査

日付：2026-10-17（JST）。**STEP2精度ゲートHOLD／STEP3未着手**。

## 改善対象
v0.2.21は整数所持数を確率分布で計算していた一方、`outcome.eligible`（抽選可能回数の期待値）をそのままスキルストックの非線形遷移へ渡していた。実際には早期満杯か遅い満杯かで抽選可能回数が分岐するため、平均を先に取るとストック上限・ピティ境界を越える確率が変わる。

## 実装
- `integerPocketTransitions` に「所持数×そのバッチ内の抽選可能な整数回数」の同時Mapを追加。所持数・食材・きのみ・いつのまに育成の従来の周辺集計を維持し、新たに `eligibleDistribution` を返す。
- `advanceSkillProcStateByHelpCounts` は各整数回数で既存 `advanceSkillProcState` を実行した後に枝確率で合成。スキル1/2回ストック、ピティ不発天井、回収・離脱時の待機スキル消去は変更なし。
- 無効な確率値や確率質量合計が1ではない状態を拒否する。

## 手計算可能な境界例
初期0、所持枠4、きのみ1個が50%／食材4個が50%、完了おてつだい4回：
- 抽選可能回数1回：50%、2回：25%、3回：12.5%、4回：12.5%。期待回数は1.875。
- スキルが毎回確定発動、ストック最大2回：1回ストック50%、2回ストック50%、期待**1.5**回。
- 従来の期待回数1.875を直接遷移させる方法では期待ストック1.875回となり**0.375回の過大**。これは人工境界ケースであり、実ゲーム週間エナジーの誤差改善率ではない。

## 追加回帰（6件）
抽選資格回数の非隣接枝／ストック上限2／満杯後の抽選停止／ピティ混合／確率質量の不正入力／7日間のエナジー内訳保存。
