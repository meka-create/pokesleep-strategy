# STEP 2 M2 — 回復役2匹の優劣未検証警告（2026-10-18）

## 変更理由

[M1 R02感度分析](STEP2_M1_R02_HEALER_SENSITIVITY_20261018.md)および[全5組の横並び検算](STEP2_M1_ALL_FIVE_RANKING_SENSITIVITY_20261018.md)では、**ヒーラーの人工的なメインスキル率0.75倍と1倍で、ヒーラー1匹／2匹のモデル順位が逆転**した。21食を確定初期食材にしても同様であり、主要不確実性は回復スキル発動時刻・個体間げんき相関にあると考えられる。

しかし、**これは同一モデルの感度であり、実ゲームの独立順位照合ではない**。モデル上の週間エナジーだけを見てヒーラー2匹構成を「最適」と断定するのは不適切。STEP 2の完了優先ロードマップでは、未検証の相対評価を無警告で優位判定しない方針。

## 実装した防護（v0.2.32）

- 朝07:30–12:00、昼12:00–18:00、夜18:00–24:00の**いずれか**に、メインスキル `Energy for Everyone S` を持つポケモンが**同時に2匹以上**含まれる場合に限り、週間試算結果の警告一覧へ次を表示する。

> げんきオールSを2匹以上同時編成した場合、回復スキルの発動時刻・複数個体のげんき相関は未検証です。試算エナジーだけでヒーラー1匹と2匹の優劣を確定しないでください。

- 単独ヒーラー、2匹だが昼間に同時編成しない場合、睡眠編成にのみ2匹含まれる場合にはこの**特定警告**は出さない（一般的な暫定試算の警告は残る）。
- 週間の `total`、`berries`、`cooking`、`skills`、所持品計算や保存済み入力形式は**一切変更しない**。警告表示のみで、自動編成の検索・順位判定は導入しない。
- `tests/simulator.test.cjs` で日中1匹/2匹、昼だけ2匹、睡眠だけ2匹の条件を検証する。
