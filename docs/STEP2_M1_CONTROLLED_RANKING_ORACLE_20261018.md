# STEP 2 M1 — 5組の編成比較の制御条件・独立きのみ順位監査

2026-10-18。対象：`scripts/step2-m1-controlled-ranking-oracle.cjs` / `tests/step2-m1-controlled-ranking-oracle.test.cjs`。

**結論の適用範囲：B級の人工的なきのみ限定条件。元の5組の実ゲーム混成順位（R01〜R05）は依然として全件未検証。STEP2 HOLD／M1 PARTIAL／STEP3未着手。**

## 試験の意味

M1の「どのチームが強いか」を検証するための入口として、同じ睡眠パーティ・同じ個体箱・同じげんき回復を維持し、昼間の編成だけを変えたときの**きのみ獲得による相対差**を、週間モデルと独立した1分刻み時計算で検算する。これはスキル役を使った場合の「ヒーラーが強い」という検証ではない。**この試験中、ヒーラーの回復スキルも食材役の食材生産も意図的にゼロ**である。

## 人工条件

- Lv50／性格まじめ／サブスキルなし／リボンなし。10個体（ライチュウ×5、プクリン、サーナイト、フシギバナ、リザードン、バクフーン）。
- すべての種族の **食材抽選率0、メインスキル抽選率0、所持枠100万** に一時変更し、`finally` で元に戻す。実ゲームではこの条件にできない。マスターの種族速度、タイプ、得意タイプは共有するが、**きのみ強さ・Lv50速度係数・げんき速度・減少タイマー・離脱時の進捗破棄・睡眠回復・曜日境界は別実装**。
- フィールド：ゴールド旧発電所、フィールドボーナス25%、いいキャンプOFF、料理なし、初期げんき30、睡眠スコア80。
- 固定睡眠：毎日0:00〜7:30のライチュウ5匹。朝7:30〜12:00、昼12:00〜18:00、夜18:00〜0:00の6種類の編成を比較。翌月曜4:00の未回収分は前週のきのみとして加算しない。
- 5組のペア構成は既存R01〜R05の形を流用。ただし、**既存M1のR01〜R05の週間エナジーには食材・スキルが含まれるため、この制御条件での順位が一致しても既存の順位を合格に昇格させない**。

## 実行・合否

`npm run m1:controlled-ranks` で6種類のモデル値と独立値、5組のモデル差と独立差、各差の符号（A/B/TIE）を出力する。

- モデル6構成の `berries`・`total` と独立1分計算の週間きのみ総量が厳密一致すること。
- `cooking=0`、`skills=0`、`sneaky=0`。全10個体の独立きのみ寄与の合計が独立総量に等しいこと。
- ペア5組の差分と優位符号が独立参照と一致すること。
- `originalStochasticRankingValidated=false`、`originalStochasticRankingPairsValidated=false`、`actualGameWeeklyValidated=false`、`step2=HOLD` を維持。
- 実測値ではなく、上記CIで確認した人工制御条件の数値だけを記録する。

## 今回埋まらない不足

- メインスキル29種の実際の発動時刻と効果、げんき回復スキルと仕事回数の相関。
- 食材確率・食材ゲットの複数種同時抽選・共有バッグ・21食の料理成立率。
- 実ゲームでの週ごとの乱数変動と、R01〜R05の実際の順位。
- M01〜M04およびP04の**全要素を含む7日間の独立定量照合**。

今回の結果は制御条件での比較器の改善材料であり、M1の14条件で9件B照合・5件未検証、5組のゲーム順位は未検証を維持する。
