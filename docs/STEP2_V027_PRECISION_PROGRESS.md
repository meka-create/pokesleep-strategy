# STEP 2 v0.2.7 — 継続改善・実装監査

更新：2026-10-16。**STEP 2は完了・精度合格扱いにしない。**

## 今回の変更

1. **料理後のげんき回復をVer.3.5.0仕様に修正。** 食前げんき0〜10は+9、11〜20は+8、21〜30は+7、31〜40は+6、41〜50は+5、51〜60は+4、61〜70は+3、71〜80は+2、81〜149は+1、150は+0。旧モデル最大+5の先祖返りを解消。
2. **きのみバースト**、**ばけのかわ**の自分／他4匹の獲得きのみを、各個体のレベル・タイプ・好みボーナスで直接計算。ばけのかわの大成功18.5%は期待値として扱う。
3. **げんきエールS**、**ほっぺすりすり**の基本回復量を追加。げんきが一番低い対象への優先確率は公式未公開のため「最低げんき優先70%＋均等抽選30%」と仮定。ボーナス発動は未対応。
4. **ナイトメア**の直接エナジーと、あくタイプ以外のチームメンバーへのげんき-12/発動を実装。
5. **食材セレクトS／きょううん／かいりきバサミ**：種族ごとに確定した3〜4種類の食材プールから、均等期待値として材料・食材バッグに加算。きょううんは食材の当選率86%を使用。追加かけら・かいりきバサミ条件付き増分は未計上。
6. **ビルドアップ**：発見済み食材の候補に対する食材ゲット基本効果と、料理大成功確率上昇の一部を反映。
7. **つきのひかり／きのみジュース**：自己回復／チーム回復の基本効果を追加。追加のランダム回復・アイテム入手は未計上（きのみジュースは本ツールの他アイテム非使用方針）。
8. **余剰食材投入**を設定可能。ONの場合はその食事のレシピ成立後、鍋の空きを余った食材の基礎エナジーが高い順に満たす。追加食材のエナジーにレシピLv70ボーナスを**掛けない**。必要食材数を超えては投入しない。毎食の局所的な選択なので翌食への食材温存を最適化しない。
9. **料理大成功の期待値**を設定可能。ONの場合は平日10%・日曜30%（コミュニティ推定）と、料理チャンスSのレベル別+4～10%／発動、最大追加+70%を近似。料理が大成功した場合の追加倍率は平日2倍・日曜3倍。確率の分布とスキル蓄積のリセットは簡易期待値処理。
10. **ユーザー指定除外7種類**（ゆびをふる・ものまね・へんしん・オールマイティー・ゆめのかけらゲットS・同ランダム版・はどうだん）は引き続きメインスキル効果を一切計上しない。これらを持つ個体の通常のきのみ・食材は計算対象。
