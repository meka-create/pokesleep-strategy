# STEP 2 v0.2.20 — 独立1分刻み7日間ベンチマーク・多条件監査

日付：2026-10-17。**STEP 2精度ゲート：HOLD**。STEP 3未着手。

## 目的

v0.2.19で「Lv1ライチュウ5匹、スキル0%、食材0%、料理なし、開始げんき100、睡眠スコア0、補正なし」という1条件の7日間計算を独立の1分刻み参照値（70750エナジー）と照合できた。ただし1条件だけでは睡眠回復タイマーの再起算、フィールドきのみ補正、開始げんきが異なる条件を検証できないため、比較パターンを増やす。

## 新規独立オラクル

`tests/reference-benchmark.test.cjs` へ `oracleWeekWithRecovery(start,score)` を追加。

- 本番 `simulate`、`advanceEnergyTimer`、`energySpeed`、`recoverFromSleep` を呼ばない**独立実装**。1分ごとに生産進捗を積み、10分が経過したときのみげんき-1。定義済みの速度帯0.45/0.52/0.58/0.66/1と2200秒おてつだい周期を採用。
- 各日07:30–24:00の990分と、月曜～土曜の6夜の睡眠450分を算入。睡眠スコアに応じて朝のげんき回復を `ceil(min(100,current+round(score)))` で適用。実際にげんきが増えた場合、10分減少タイマーを0へ再起算。おてつだい進捗は睡眠を跨いでも維持。
- 最終日・日曜24:00～翌月曜04:00の睡眠エナジーは、旧週の回収操作がないため未受領として合計に加算しない。
- きのみエナジーは `pokesleep-tool src/util/Berry.ts` の独立オラクルで計算。ライチュウLv1のきのみ2個／おてつだい、5匹固定の同一パーティ。
- 参照元：https://github.com/nitoyon/pokesleep-tool/blob/master/src/util/Berry.ts および https://github.com/nitoyon/pokesleep-tool/blob/master/src/util/Energy.ts
