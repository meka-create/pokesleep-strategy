更新：2026-10-16。**精度ゲートは保留。STEP3には移行しない。**

## 機能追加
今回、以前未対応だった次の7種類について**基本的な計算経路**を追加した。

| スキル | 算入した基本効果 | 未対応・近似範囲 |
|---|---|---|
| おてつだいサポートS | Lv別6〜12回のおてつだいを、1匹の対象を均等抽選する期待値で、きのみ・食材として通常所持上限とは別枠（最大999）に計上 | 実際の抽選、追加おてつだいによるスキル連鎖、厳密所持数 |
| おてつだいブースト | 発動者と同じタイプの異なる種族数1〜5とスキルLvによる追加おてつだいを5匹に配分 | 追加おてつだいによるスキル発動は無し。別枠999の厳密な抽選・所持は近似 |
| りゅうせいぐん | 発動者と仲間のきのみをLv・同タイプの異なる種族数で計算。ラティアス／ラティオス同時編成ボーナスも反映 | 期待値以外の確率的なばらつき、スキルストック |
| サイコブレイク | Lv別1408〜7274の直接エナジーとフィールドボーナス | マゴのみゾーンの持続強化・上限は未計上 |
| いやしのはどう | Lv別6〜22の対象げんき回復を対象2匹への均等期待値で計算。追加おてつだいとラティアス／ラティオス同時ボーナスも基本反映 | 回復対象の確率・実抽選・所持上限の近似 |
| みかづきのいのり | Lv別3〜11のげんきオールと同タイプの異なる種族数別のきのみ追加獲得 | 時刻、端数・スキルストックなど |
| たくわえる | 長期的な1発動当たり平均エナジー（Lv1〜7の配列）を計算 | たくわえ／はきだす抽選、蓄積状態、週末未放出、編成変更でのリセット |

**現行249種／スキル36種類**：基本効果を暫定・部分対応 **29種類**、ユーザー指定によるスキル効果の完全除外 **7種類**、基本経路のないスキル **0種類**。ただし29種類の全効果を完全再現したことは意味しない。

## 残る重要な精度ブロッカー
1. **たくわえるの状態遷移**：週の初期蓄積0回、有限期間の放出・未放出を追跡し、編成を外れた際に0へ戻す。長期期待値だけでの7日計算は偏る。
2. **スキル連鎖と所持上限**：通常の所持上限と追加おてつだい別枠999の乱数・所持数、スキルの実際の発動時刻、2回ストック、初期ストック等の精密化。
3. **サイコブレイク・いやしのはどう等の複合効果**：きのみゾーンの期間・累積率／いやしのはどうの正確な抽選／条件付き効果を含めた残る未計上をなくす。
4. **料理の週全体最適化と食材在庫**：現状は毎食の貪欲法。追加食材の使いすぎ、翌食・翌週の温存、食材バッグの実整数状態を扱えていない。
5. **独立ベンチマーク**：pokesleep-toolの計算エンジンと同一個体・同一編成・同一条件で差分を定量化する。少なくともきのみ・食材・スキル別に比較し、ズレの原因を追跡。
6. **実機ゲート**：Android Chromeでの操作、GitHub Actionsの実行結果、保存復元・画面表示を確認する。
