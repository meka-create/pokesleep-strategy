# STEP 2 v0.2.10 — 睡眠中のげんき減少と回復上限の修正

日付：2026-10-16  
判定：**コード修正・互換JS回帰テスト PASS。STEP 2の精度ゲートは継続HOLD。**

## 重大な既存不具合
v0.2.9以前の夜間処理では、0:00–7:30におてつだい・スキル・所持上限を進めていたが、ポケモンのげんきは一切減らさなかった。このため、夜間におてつだい速度が不自然に高く維持され、きのみ・食材・スキル発動の期待値を過大評価する条件があった。

また睡眠後のげんき回復で上限150を許容していた。しかし、通常の睡眠回復によって到達できる上限は**100**。サブスキル「げんき回復ボーナス」を自身が習得した個体のみ**105**（Ver.2.7.0以降）。メインスキル・料理での回復上限150と混同していた。

## 修正内容
1. **睡眠中の7時間30分も10分につきげんき1減少。** 15分刻みの計算では区間中央のげんきを使い、その後1.5減少する。睡眠中も生産といつのまに育成を計算。ユーザーは一切触らないので途中の回収はしない。
2. 睡眠スコア、受け手のせいかく、睡眠パーティ中の「げんき回復ボーナス」の人数に基づき、翌朝の回復を計算。自身がそのサブスキルを持つ個体のみ105、他は100上限。睡眠前から上限を超えるげんきを保持していた場合に、睡眠回復処理がげんきを**下げる**ことはない。
3. **ボックス内の通常5％睡眠回復を計算しない**というユーザーの確定仕様を維持。睡眠用パーティ5匹だけ回復する。
4. 月曜4:00の週切替で計算を停止し、最後の夜の4:00–7:30は旧週のエナジーへ計上しない。最後の夜の7:30回復・回収も旧週に発生させない。
5. 結果画面へ「睡眠中のげんき推移」を折りたたみ表示。7夜の「睡眠前平均 → 回復直前平均 → 回復後平均」（最終夜は翌月曜4:00で終了）を表示。数値は丸めた平均を表示するが内部計算は小数で進める。
