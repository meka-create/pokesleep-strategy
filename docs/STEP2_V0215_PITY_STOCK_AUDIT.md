# STEP 2 v0.2.15 スキル不発天井・ストック連動精度監査

日付：2026-10-17。**STEP 2計算精度ゲート：HOLD**（STEP 3未着手）。

## 変更目的

v0.2.14では実際のおてつだい抽選率に、有限期間用ではない「ピティ込み長期平均率」を毎回掛けていた。この方式は、おてつだい失敗が一定回数続いたあとに確定成功するスキル不発天井の有限期間挙動、および2回ストック満杯時の抽選停止・連続不発状態を正しく表現できない。

## 実装

- `emptySkillProcState(threshold,cap)` / `advanceSkillProcState(state,expectedHelps,rate)` / `skillProcMarginal(state)` / `clearSkillProcStock(state)` を導入。確率状態は「待機ストック 0..cap × 連続不発回数 0..threshold-1」の同時分布。
- 各通常おてつだいは補正後の**素のスキル抽選率**で発動抽選。不発なら連続カウント+1、天井に到達する回は確定成功。成功時にはカウント0に戻す。待機ストック上限1/2に達したあとでは追加の抽選をしない。
- 回収時には確率分布に応じた発動期待回数を既存の29スキル部分モデルへ渡す。待機ストックは空に戻し、連続不発回数の残存分布は保持する。追加おてつだい別枠からはスキル抽選しない。
- パーティ変更時には元のチームと新チームに含まれる個体の待機スキルをキャンセルし、連続不発履歴は保持する。同じ集合の単なる並び替え・初回の編成指定では取り消さない。編成から外れた通常／追加おてつだい所持品を消すv0.2.13処理は維持。
- 基準天井回数は一次実装 `nitoyon/pokesleep-tool src/util/PokemonIv.ts` に合わせ、きのみ・食材とくい78回、スキル・Allとくいは `ceil(142000 / species.frequency)`。頻度0の例外は78回とする。社区推定には40時間÷基準おてつだい秒（144000秒）もあり、正確な閾値の個体別差は今後検証。ユーザー指定の除外7スキルは引き続き発動効果を計上しない。
- 0%抽選率はスキルが発動しない特例として扱い、勝手に天井確定スキルを発生させない。

## 試験

- 新規8テスト：天井境界、回収後の不発履歴、ストックと不発回数の相関、満杯中の停止、15分端数、編成交代、同一編成、入力と0%抽選。
- 従来の固定睡眠、月曜04:00切れ目、ぼっち5%睡眠回復除外、食材バッグ、料理、全7除外スキル、CSV/JSON互換の回帰を維持。
- Node.js 22 GitHub Actionsで `npm run check` と生成HTML同一性を検証し、結果が確認できたときのみPASSと記録する。

## 残る未検証・近似

- 15分刻みの端数おてつだいはベルヌーイ1回に置き換える**期待値近似**であり、個別の時間間隔・発動秒・所持個数は再現していない。
- 実ゲームの通常5回おてつだいクールタイム、チーム再編成に伴う追加おてつだい抽選・不発カウント特殊増分、二度のスキル発動による割り込みと回復発動時刻は未再現。
- おてつだいがバッグ満杯で行われない時間やいつのまに育成との接合は簡易化。料理・追加食材の整数性・レシピ週間最適化・スキル条件付き効果の一部が未対応。
- 具体的な週間エナジーの実ゲーム測定値とのベンチマーク、Android Chrome実機確認は未実施。
- ポケスリの仕様や参照マスターが変化した際には再確認が必要。
