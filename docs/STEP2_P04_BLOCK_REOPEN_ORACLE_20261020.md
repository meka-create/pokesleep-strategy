# STEP 2 M1/M2 — P04 満杯→解放時のスキルストック・不発履歴（v0.2.54）

日付：2026-10-20

## 検証の位置づけ

M1のP04では「バッグが7日間ずっと満杯で料理なしなら、食材獲得スキルの実発動は0回」という限定B級参照がある。
しかし待機スキルのストックと不発履歴、料理で空きを作った次回操作での回収条件はゲーム実測で未検証。
前回2版の比較保留警告追加から方針を変え、人工短時間操作列の**状態分布を独立の全列挙と比較**する。

## 人工条件と検算方式

1. 食材バッグ5/5のまま、2回の抽選可能なおてつだい→満杯回収でスキルを発動せずストック維持。
2. 同じく2回おてつだい→満杯回収。ストック・不発履歴を持ち越す。
3. 料理により共有バッグの空きが発生した条件を人工指定。新たな抽選可能なおてつだいを挿入せず、待機ストックを発動して0へ。不発履歴は維持する。
4. さらに2回おてつだい→空きのあるバッグで回収。

独立リファレンスは6抽選位置の最大64通りの当落を全列挙。もう一方の計算は既存のスキル抽選・天井・ストックAPIを呼ぶ。
5条件（抽選率0/0.25/0.4/1、天井2/3/5、ストック上限1/2）に対し、満杯中と解放後の（ストック数, 連続不発回数）同時分布、
解放直後の期待発動回数、次の空き回収の期待発動回数を比較する。

## 証拠と限界

- **B級：人工指定した当選率と「満杯では発動せず、ストックと不発天井を維持」というモデルの前提に対する独立数学検算**。ゲーム固有の発動率・満杯時抽選仕様・待機履歴を実測したのではない。
- **元のP04は常時満杯の発動0回だけB級外部仕様照合**。新規短時間オラクルは14条件の主マトリクスの独立比較10/14を11/14にはしない。
- 週次本体の式、14条件凍結データ、5組の順位、CSV16列、JSON保存、生活制約・固定睡眠5匹は全て不変更。
- 必要な追加証拠：実ゲームの満杯待機・料理での開放・次回回収の発動／不発履歴、複数個体の所持枠との相関。
- M01〜M04の外部週間比較0/4、R01〜R05の実ゲーム順位0/5、実測週0、M1/M2/M3 PARTIAL、M4未着手、**STEP2精度HOLD／STEP3未着手**。
