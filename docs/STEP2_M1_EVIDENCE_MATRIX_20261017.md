## 目的と成果物

旧ロードマップの「計算を精密化し続ける」を止め、現行モデルに**独立根拠のある部分と根拠が未取得の部分をラベル付けする**。14条件と5つの候補編成比較を、プログラムから同じ入力で再現し、数値・参照情報・要調査をJSON形式で出力する。

- 実行：`npm run m1:audit`。標準出力の `M1_REPORT_JSON=` 以降が機械可読なベンチマーク結果。
- 検証：`tests/step2-m1-audit.test.cjs`。14条件、5比較、数式照合、精度ゲートHOLDを検証する。
- **独立性の証拠階級**：A＝複数回のゲーム実観測を記録した比較、B＝ゲーム仕様に基づく独立数式／手計算／別刻みの時間計算または**条件を完全指定した数学的な人工分岐**、C＝同じエンジンの自己整合性・試算結果。人工分岐Bの成功をゲーム抽選確率の測定と取り違えない。
- **注：現在のA級実測は0件。** B級の一致も実ゲーム混成チームでの週間誤差率を表さない。C級は「正確」と判定してはいけない。
