# STEP 2 M2 — たくわえるの待機スキル0/1/2回分岐（2026-10-23 / v0.2.67）

## 問題と範囲

`src/simulator.js` の既存 `advanceStockpile(state,expectedTriggers,level)` は、メインスキル待機ストック分布 `P(N=0),P(N=1),P(N=2)` から計算した平均発動数 `E[N]` に対し、「整数回の確定発動＋端数の1回発動」の形で蓄積・放出を処理していた。実際のモデルがすでに保持している `skillProcMarginal(triggerState)` の分岐を捨てるため、**たくわえるの非線形・履歴依存の分岐は平均化と交換できず**、期待報酬と次回蓄積確率の両方が変化する。

これは人工の確率分岐計算で独立に再現できる**既存モデル内のP1不整合**。実ゲームの抽選確率・7日間スコア・最適編成順位が確定したという意味ではない。

## 再現条件（レベル1、初期たくわえる蓄積0）

* 待機発動数 `N=0` が50%、`N=2` が50%、`N=1` は0%。`E[N]=1`。
* レベル1の放出表は蓄積0回で600、蓄積1回で1020。蓄積10以外は放出25%、積み増し75%とする、既存モデルの**人工条件**。
* 旧平均近似：`advanceStockpile(initial,1,1)` の報酬期待値は **150**。
* 独立全分岐：`N=0` の報酬0、`N=2` の1回目報酬150、2回目報酬 `0.25×150 + 0.75×(0.25×1020) = 228.75`。したがって期待報酬 **0.5×(150+228.75) = 189.375**。
* 旧モデルとの差 **+39.375** は人工1回収のこの条件に限定する。ゲーム週間の補正量や正解率ではない。
* 新しい次回蓄積分布 `[P(k=0),P(k=1),P(k=2)] = [0.625,0.09375,0.28125]`。旧 `E[N]=1` による状態 `[0.25,0.75,0]` とも一致しない。

## 修正と回帰

* `advanceStockpileByReadyStock(state, readyStock, level)` を追加。既存の `P(N=0..2)` の各整数回分岐を独立に進め、報酬期待値と11状態確率を重み付き合成する。確率・質量を検証し、不正値は拒否する。
* 週次本体 `collect()` の「たくわえる」だけを分岐計算へ切替。既存の `advanceStockpile` APIは他の回帰のため保持し、他スキルは変更しない。
* `tests/step2-stockpile-ready-stock.test.cjs` で0/2混合の独立算術、0・1・2回の確定ケース、蓄積10の放出上限と次回積み増し、不正確率拒否、フワンテ5匹の7日試算を検証する。
* 16列CSV、保存JSON形式、睡眠5匹固定、月曜04:00、料理、バッグ、凍結M1 `docs/STEP2_M1_BASELINE_V0230_20261017.json` は変更しない。

## 追加監査：スキルLv.7の蓄積8〜10回の報酬（P1）

現行報酬表に **Lv.7の蓄積8/9/10回だけ旧値 46,370 / 59,876 / 82,386 が残っていた**。2026-10-23に外部照合した[攻略・検証Wikiの現行表と旧Ver.2.12.2以前の併記](https://wikiwiki.jp/poke_sleep/メインスキル/エナジーチャージ/たくわえる)および[PokéSleep Super Wikiの現行表](https://wiki.pokesleep.com/ja/main-skills/stockpilechargestrengths)では、現行は **48,621 / 66,629 / 90,940**。蓄積8/9では「はきだす」確率のモデル値25%、蓄積10は100%で、1発動報酬に差が生じる。この現行表との明示的な不一致を修正し、レベル1〜6およびLv.7の蓄積0〜7回は不変更。3境界の固定期待報酬と確率保存則を別テストに追加。外部資料の更新値への追従であり、実ゲーム週間発動確率の測定ではない。
