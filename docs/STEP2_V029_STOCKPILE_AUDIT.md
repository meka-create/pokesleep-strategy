# STEP 2 v0.2.9 — たくわえる有限期間・編成変更監査

更新：2026-10-16。**STEP 2の計算精度ゲートは引き続き保留（HOLD）。**

## v0.2.8からの改善

v0.2.8の「たくわえる」は、スキルの発動期待値に**交代しない無限期間の平均エナジー**を掛ける方式だった。この方式は月曜日に蓄積0回から始まること、週内で編成を外れること、日曜日の未放出の蓄積を考慮できず、特に短時間運用を誤評価する。

v0.2.9では、**蓄積0〜10回の11状態の確率分布を個体ごとに追跡**する方式へ移行した。

- 月曜日の開始時点では全個体の蓄積は0回と仮定する。
- 0～9回蓄積時、発動ごとに「たくわえる75%／はきだす25%」の抽選を行う。10回蓄積後は必ずはきだす。
- 発動回数が小数の期待値の場合、整数部分を確率遷移し、端数を「その確率で1回発動する」近似として適用する。実際のスキルストック／発動時刻の完全な再現ではない。
- **はきだす時のエナジーのみ計上**。蓄積そのものにはエナジーを加算しない。
- 朝→昼、昼→夜、夜→睡眠、睡眠→朝の切り替えで個体がチームを離れた場合、蓄積の確率分布を削除し、次の出場では0回から再開。
- 翌週月曜4時で計算を止め、まだ放出していない蓄積は前週のエナジーには加算しない。
- `stockpileResets`, `stockpileExpectedLost`, `stockpilePending` を試算結果に記録。ユーザー向けには編成変更による蓄積リセット、週末に残った未放出について警告。
- きのみ／料理／他のメインスキル、ユーザー指定で除外された7スキルの処理は従来どおり。

## 使用した数値表と未確定事項

現在使用するはきだす効果量（Lv1～7、蓄積0～10回）は、[ポケスリ総合資料サイト：たくわえる](https://wiki.pokesleep.com/ja/main-skills/stockpilechargestrengths) の値を基準にした。確率75/25は実測からの推定であり、公式公表値とは限らない。

**情報源間の数値差に注意**：[Game8のたくわえる記事](https://game8.jp/pokemonsleep/643232) はLv7の10回で90,940と記載する一方、資料サイトでは82,386と記載する。ゲーム内最新の効果表での独立確認が終わるまでは、この差異を未確定事項として残す。現在の計算は資料サイト側の値で、**絶対値の精度を保証しない**。
