# STEP 2 v0.2.25 — 共有食材バッグ満杯時のスキル発動ブロック監査

日付：2026-10-17（JST）。**STEP2精度ゲートHOLD／STEP3未着手**。

## ゲーム仕様との不一致
攻略・検証Wiki「食材ゲット」「食材セレクト」「ビルドアップ」の各仕様では、食材バッグが満杯の状態では食材獲得スキルの発動が拒否され、空きができるまで発動できないとされる。従来エンジンは食材追加が0個の一方で、`status.skillCount` を増加させ `clearSkillProcStock` により待機スキルを消去していた。

出典：
- https://wikiwiki.jp/poke_sleep/メインスキル/食材ゲット
- https://wikiwiki.jp/poke_sleep/メインスキル/食材セレクト
- https://wikiwiki.jp/poke_sleep/メインスキル/料理アシスト/ビルドアップ

## 修正範囲
- `blockedIngredientSkill` は、共有食材バッグの**容量が明示され満杯**の場合に限り、`INGREDIENT_MAGNET` 4種（食材ゲット・プラス・プレゼント・ビルドアップ）および食材セレクト3種の発動を止める。
- ブロックされたスキルはその回収で`triggers=0`。料理チャンスや追加食材などの付随効果も計算せず、スキルストック・不発天井の同時分布を消去しない。`bag.skillState` にも待機分布を保持。
- バッグに空きができた後の**次回回収操作**では待機ストックの発動を再度評価。通常のきのみ・食材回収や非食材スキルは妨げない。
- v0.2.24の個体所持食材数分布・除外7スキル・0:00～7:30無操作・月曜4:00未回収・16列CSV/JSON形式は維持。

## テスト追加7件
対象全7種類のブロック、非対象スキル、容量未設定の扱い、入力検証、食材ゲット5匹の満杯週で発動0回と抽選資格保持、食事後の空きによる発動再開、通常の直接エナジースキル非阻害。
