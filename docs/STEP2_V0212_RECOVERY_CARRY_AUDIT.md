## 修正した2件の主要な計算誤り

### N01 げんき回復▼せいかくが0.80倍になっていた
旧 `natureFactor` は、食材確率・スキル確率と共通の下降値0.80を使用しており、睡眠時・げんきオール・自己回復・げんきエールなどの回復を過小評価していた。

**対応**：`recoveryNatureFactor` を分離し、げんき回復上昇1.20倍、下降0.88倍、無補正1.00倍に統一。食材確率・スキル発動確率の下降値0.80はそのまま維持。

出典：
- https://github.com/nitoyon/pokesleep-tool/blob/main/src/util/Nature.ts （`energyRecoveryFactor`）
- https://wikiwiki.jp/poke_sleep/せいかく

### N02 進化回数「-1」で所持上限が5個減っていた
`src/master.js` の種族データには `evolutionCount=-1` の種族・フォルムが38件ある。旧コードは `carryLimit+5*evolutionCount` を無条件適用し、特別な種族や未進化種を誤って5個少ない所持上限で計算していた。

**対応**：進化回数のマイナス値は「進化補正なし」とする。ただし通常のピカチュウは進化後の初期所持数が22個（元データ17個＋5）のため、**通常個体だけを明示補正**。ホリデー等の別フォルムへは補正しない。

例（サブスキル・リボンなし）：

| 種族 | 実装上の補正後初期所持上限 |
|---|---:|
| ピカチュウ（通常） | 22 |
| ライチュウ | 31 |
| フシギバナ | 27 |
| プクリン | 32 |
| イーブイ | 12 |
| タマザラシ | 9 |
| デデンネ | 19 |
| ピカチュウ（ホリデー） | 20 |

いいキャンプチケットの所持上限1.2倍は、現在の規則に合わせ `Math.ceil(最大所持数*1.2)` に修正（小数の所持枠を扱わない）。

出典：
- https://www.pokemonsleep.net/news/323735303337333934353639323635313533/ （Ver.2.9.0進化による所持数の統一）
- https://wikiwiki.jp/poke_sleep/最大所持数
- https://wikiwiki.jp/poke_sleep/ライチュウ
- https://wikiwiki.jp/poke_sleep/フシギバナ
- https://app-psl.pokemon-support.com/hc/ja/articles/29517911255065--いいキャンプチケット-の効果がありません
