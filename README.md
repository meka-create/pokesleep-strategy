## 確認方法
1. ZIPを展開し、ルートの `index.html` を開く。
2. 「v36の作戦画面を開く」からU3へ。イベント条件は準備週で展開される。
3. 画面下部の「作戦」「準備」「ボックス」フッターからタブ移動する。
4. 上部「開発用・日時切替」を開く。ボタンは「準備週」「月曜・開始直後」「水曜・週途中」の3つのみ。以前の「準備画面へ／作戦画面へ」は撤去済み。
5. U3で日時切替しても作戦タブを維持、U2で日時切替しても準備タブを維持。保存状態も維持する。
6. 初回提案からやり直す場合は明示的に検証データ初期化。日時切替だけで消去しない。
