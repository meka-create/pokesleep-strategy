## この版で確認するもの
- イベント候補は自動取得。Pokémon SleepのJST04:00の終了時刻を過ぎた候補は表示しない。
- 取得状況や保存状態の説明ラベルは出さない。
- イベント補正はイベント名＋箇条書きだけ。未選択時は非表示。
- 備蓄のカテゴリ数：3／2／1。イベントごとにユーザーが選ぶため初期の選択なし。
- 3：カレー・サラダ・デザートすべて。2または1：対象カテゴリをボタンで選択。指定数に満たないと保存しない。
- **保存**するまでイベント条件・備蓄カテゴリ選択は保存済みデータに反映しない。
- 保存済みのイベント別選択は再読み込みで復元。旧版に存在しない設定を「3」に自動補完しない。
- いいキャンプチケットの初期ON／明示OFFの維持、開発用日時切替、作戦／準備／ボックスのフッターを維持。
- **実レシピ選定・必要食材数・カテゴリ別のエナジー計算は未実装**。備蓄選択は今はUIと保存の確認だけ。
