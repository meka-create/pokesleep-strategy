## 変更
- 検証用のイベント情報取得と二段階反映UI（サンプルデータ）は撤去。ただし旧版で保存済みのイベント補正データは引き続き表示する。
- 準備週ではイベント条件を常時展開し、折り畳み操作を非表示。
- いいキャンプチケットの新規設定初期値はON。明示して保存したOFFは維持。
- イベント週の料理は未確定でも事前の条件保存が可能。**未確定のまま作戦提案ができるわけではない**。
- 備蓄方針は通常3カテゴリ（カレー／サラダ／デザート）の高エナジー料理を同優先度で扱う方針を示す。集中備蓄と食材数計算はF3の未実装項目。
- イベント補正は情報があれば強調表示し、なければ「未確認」と明記。実際の自動取得F2は未実装。
- 開発用日時切替とフッタータブは保持。ボックスは仮画面。

旧バージョンの保存データを消さず、検証データの初期化は開発メニューで明示操作した場合だけ。Android実機受入まではE6 HOLD。
