# ポケスリ作戦室 E6 v34 検証専用ZIP
2026-11-07 / E6は**実機NG後の再受入候補**です。自動テストの合否とPixel 7a実機のUX承認は別です。

## 始め方
1. ZIPを展開し、ルートの`index.html`をAndroid Chromeで開く。
2. `E6検証を始める`を押す。U3で**開始日2026-11-09、シアンの砂浜、カレー**を検証用イベントとして明示保存する。
3. 準備画面へ移り食材在庫を保存し、各画面上部の開発専用メニューから**準備週／イベント開始／イベント中**を1タップで切替える。ガイドのページへ戻る操作は不要。
4. 採用済み作戦を保持したまま準備週に戻しても、準備週に未来の週間編成を表示してはいけない。イベント中に戻した場合は採用済み作戦を表示する。
5. E6テストを最初からやり直す時だけ、開発メニューの「検証データを初期化して、最初から」を使用する。

## 制約
- このZIPは**`index.html`／U2 v34／U3 v34／READMEの4ファイルのみ**。旧v0.5.6と過去プレビューは含めない。
- 段階切替は開発用であり、本番PWAでは日時と保存状態により自動判定する。
- 準備へ過去時刻を戻した際に既に開始後在庫があれば、開始前の基準在庫を表示し、過去の値で開始後の保存を上書きしない。
- **保存済み作戦は段階切替だけでは削除されない**。イベント開始直後の未採用画面を再確認するには明示初期化し、条件・在庫を再設定する。
- `file://` のAndroid Chromeの保存や遷移動作は必ず実機で確認。失敗をPASSとしない。
- U4/U5/F工程（実個体接続、同一オリジン保存、エナジー最適化）は未完成。E6をPASSにするのはPixel 7aでのユーザー明示承認後。
- E5 v33と本番mainは変更せず、開発用はDraft PR #114で隔離する。
