## 手順
1. ZIPを展開し、直下の `index.html` を開く。
2. 「v38の作戦画面を開く」をタップ。
3. イベント候補の取得は起動時自動。ボタン操作は不要。通信不能時は2026-11-07時点の同梱候補を明示。
4. 「したごしらえウィーク vol.1」をプルダウンで選択すると、開催日とイベント補正を即座に画面へ仮反映する。**保存済みイベント条件と在庫は一切変更しない**。
5. フィールド・イベント週の料理等を確認し、**保存**を押して初めて条件を確定。
6. 保存後に再読み込みしてイベント選択と明示キャンプOFFを維持するか確認。
7. フッター3タブと開発用日時切替は従来どおり。
