# E7 v66 — 標準ダイアログ・フィードバック監査（2026-11-11）

## 対象
現行開発版 E7 プレビュー（共通シェル・作戦 U3・準備 U2・ボックス U4・設定／バックアップ）を対象とする。既存の保存キー、CSV・JSON形式、F工程の計算は変えない。ブラウザの alert / confirm / prompt を全て独自UIに変更する。内部実装には HTML dialog 要素を使用するが、操作ボタンと文言、色、レイアウトは共通独自仕様。

OSファイル選択画面・権限確認・ブラウザの入力補助は、アプリが開く標準 alert / confirm / prompt とは区別し、本工程の対象外とする。

## ユーザーフィードバックの振り分け
| 表示先 | 適用条件 | 例 |
|---|---|---|
| 独自モーダル | 取り消し・確認が必要な変更 | 全削除、イベントの未保存条件破棄、復元、データ初期化 |
| 独自モーダル | ユーザーが認識して進む必要がある重要通知 | バックアップ復元後の再読み込み、検証時の保存保護 |
| トースト | 保存成功・一時的な操作結果 | 備蓄カテゴリ、在庫、編成、イベント、プレイヤー、個体の保存・追加・削除、書き出し |
| 画面内の入力補助 | 訂正が必要な入力エラー | 食材数、料理／きのみ選択、プレイヤー数値、CSV・JSON形式 |
| 画面内の継続状態 | 画面を見ている間、常に意味のある情報 | イベント終了、破損・ロック状態、CSV内容確認、再提案の条件 |

既存のU2・U3独自トースト関数は共通PokeUIへ委譲。ボックスの画面下部に出る短い結果テキストはトーストへ。復元内容・読み込んだ個体のプレビューは画面内に保持する。取消・Esc・背景タップは破壊的処理を実行しない。待機を伴う確認後は対象レコードを再検証する。

## 検証
JavaScriptの標準確認ウィンドウ残存0件、独自モーダルのキャンセル／続行、複数ダイアログ、トーストの表示、スマホ320/393/430px、3タブ往復、睡眠編成、ボックス、イベント切替、バックアップ、開発用初期化、既存の保存保護を自動回帰。CI2系統、Pages公開、Android実機受入を分離。

## 旧正式rootとの関係
E7プレビューとは別に、旧正式rootのindex.htmlに標準確認ウィンドウが10件残存する。以前の独立監査ではroot旧版の保全を必須としているため、E7の実機承認前に旧rootや計算エンジンを上書きすることはしない。正式版への統合はE7受入後の移行ゲートで実施する。
