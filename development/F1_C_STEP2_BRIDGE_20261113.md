# F1-C：既存STEP2週間シミュレーターとの安全な接続（2026-11-13）

## 実装と判定
- 新規 f1/f1-c-step2-simulation-bridge-v1.js：E7ボックス互換の個体構成（id/pokemon/level/skillLevel/ing1..3/mainSkill/nature/mint/ribbon=累計睡眠時間/Lv10..80）と、7日×朝昼夜・7晩の編成、イベント基本条件を受け付ける。F1-Bで固定した66種族の出典・プロフィールと旧STEP2マスターを照合し、個体ごとのおてつだい間隔・食材率・スキル率・所持枠・食材数量をSTEP2へ渡す。初期69個体以外の合法個体も対象とする。
- **E7先祖返り保護により構成を修正**：既存の src/simulator.js はbaselineコミット3691080の内容へ完全復元し不変更。F1専用 f1/f1-c-simulator-v1.js を独立モジュールとして設け、こちらだけに __f1VerifiedRates とミュウの選択スキル処理を追加。PokeF1CSimulatorとして別公開し、通常のSTEP2/E7には一切影響させない。E7 v78のUI、イベント別保存、PWA、アイコンは不変更。
- 主な出典差分：旧STEP2のゲンガー食材確率 16.1％ と、F1-B固定元 16.6％ の違いは、F1-Cの個体別確率を優先。他の65種の型/フォーム/基礎値は一致確認。別の差分を見つけた場合、旧値を黙って使用せず BLOCKED。
- 旧STEP2の「げんき経過・バッグ・スキル抽選ストック・7日21食/編成」の既存期待値モデルを再利用。**週間結果は暫定期待値（PROVISIONAL）であって、ゲーム内確定数値/最適解の証明ではない**。料理の成立分岐、睡眠中の交代、フィールドEX要素等の限界も既存警告と一緒に返す。
- **ユーザー追加承認（2026-11-13）**：ミュウには仮確定値を使用してよい。スキルの選択効果ごとに攻略・検証Wikiの暫定基礎発動率（きのみバースト2.84%、げんきオールS3.37%、中確率群4.00%、げんきエールS4.39%、エナジーチャージS［ランダム］・げんきチャージS6.40%）を採用し、性格・ミント・発動サブスキルを反映。最終的な公式確定値ではないため週間期待値はPROVISIONALのままとする。選択スキルはSTEP2の対応効果に接続。オールマイティーのみの表示なら初期のゆびをふると仮定して警告を付ける。ゆびをふる等の既存STEP2未対応効果・Lv8上限の近似も明示。メインスキルの追加アメはエナジー換算しない。ダークライのナイトメアは従来近似を維持し、別の相関誤差は未評価。未対応種族、不正個体、出典差分、食材未検証時はBLOCKED。参照：https://wikiwiki.jp/poke_sleep/%E3%83%9F%E3%83%A5%E3%82%A6 https://wikiwiki.jp/poke_sleep/%E3%83%A1%E3%82%A4%E3%83%B3%E3%82%B9%E3%82%AD%E3%83%AB/%E3%82%AA%E3%83%BC%E3%83%AB%E3%83%9E%E3%82%A4%E3%83%86%E3%82%A3%E3%83%BC
- 入力の個人CSVやニックネームを原典JSONへ保存/書き込みしない。計算結果にも個体行を返さず、モデル全体の暫定ステータス、警告、7日間の内訳のみ返す。
- テストは必要な範囲だけ：66種一致・ゲンガー1差分の優先・5体7日計算・ミュウの暫定各スキル・未選択ミュウの隔離・不正入力の停止・旧STEP2のバイト一致保護を既存E7回帰で確認。PR CIを通過後main統合、main CIとPagesデプロイを確認する。
