# F1-D 実ボックス連携・週間参考試算プレビュー（2026-11-13）

## 実装
- 受入確認URL：https://meka-create.github.io/pokesleep-strategy/f1d-preview/
- E7 v78最終受入済みのUI・保存領域・PWAアイコン・インストール名・E7プレビューURL・旧正式rootを変更しない。E7画面を独立プレビュー内で同一オリジンiframeとして表示し、作戦画面にのみ「週間参考試算」カードを非破壊的に挿入。
- E7ボックスに登録された実個体5匹を明示選択。同名/同種の個体を誤同定しないようボックスの登録位置で区別し、内容更新で選択をクリア。個体の性格・食材・サブスキル等の判定と計算はF1-B/Cを再利用。
- 選択イベントの確定済み条件・イベントID別食材在庫・プレイヤー設定・実ボックスを読み取る。旧週単位在庫は所有ID一致時に限定。E7ローカルストレージへの書込・削除を禁止。イベントやボックスが変更されたら結果を破棄。
- 今回の試算は固定5匹を月〜日の朝昼夜と7晩に共通で仮配置した28枠の参考値。曜日・時間帯の自動最適化は未実装。残期間のみの再提案でもない。確定エナジーと誤認させない。
- イベント料理「すべて」では料理カテゴリの明示選択を要求。通常の固定カテゴリではイベントの条件を適用。料理はF1-Cの1食時点でエナジー最大の既存レシピ選択近似を流用。未対応EX効果やイベント固有補正は警告。
- CSV任意欄が未記入の場合、ミント未使用・累計睡眠時間0を明示的に仮定。鍋未設定57枠、バッグ未設定で制限非適用、フィールドボーナス未設定0%を明記。個体設定・試算結果は恒久保存しない。
- ミュウはユーザー承認の暫定スキル別発動率を継続使用し、実装できない効果は明示する。
- 独立データ層：f1/f1-d-e7-input-v1.js。独立プレビュー：f1d-preview/index.html と f1d-preview/f1-d-ui.js。
- Node試験：tests/f1-d-e7-readonly-integration.test.cjs。Chromium mobile回帰：tests/f1-d-preview-browser.test.cjs と tests/preview_browser_f1_d.py。
