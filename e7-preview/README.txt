ポケスリ作戦室 E7 v62 — GitHub Pagesプレビュー／高速タブ構造
URL: https://meka-create.github.io/pokesleep-strategy/e7-preview/

【変更】3つの画面を一度読み込んで保持する方式に刷新しました。
- フッターは親ページで共通管理。タップ時にページHTMLを再取得しません。
- 作戦／準備／ボックスの往復で、スクロール位置と未保存の入力を保持します。
- 初回は各画面のDOM初期化完了時点で表示。画像の全件ロード完了は待機しません。
- 準備画面の食材画像は38個のHTML埋め込みから、共通19PNGの遅延読み込みに変更。
  同じ画像は2画面で再利用し、SWにより19種をオフラインで保持します。
- 初回表示後の空き時間に他画面を順次事前読込。時刻/イベント変更時は旧フレーム通知を無視します。
- 在庫を保存すると作戦画面に最新在庫を同期。確定したイベント週・備蓄対象変更時など、
  古いイベントを表示する危険があるときは該当画面だけを安全に再ロード。
- ブラウザの戻る履歴は親ページで管理。通知ドットも共通フッターに転送。
- 既存v50のブックマーク／旧PWA起動先は最新v51入口へリダイレクト。
- 本番通常版のトップページ（リポジトリroot index.html）は変更しません。
- 現行個体CSVは旧16列/中間17列/現行18列（まっしろミント独立列）に引続き対応。

【旧開発パネルの復活】
- 作戦・準備それぞれの画面上部に、以前の「開発用・日時切替」を折りたたみ表示。
- 開始前／開始後／週途中の日時切替は親画面の時刻と同期し、現在のタブを保持します。
- 「検証データを初期化して、最初から」は確認後、選択イベント週だけを削除。
  ボックス・プレイヤー設定・別イベント週は保持します。
- フッターの作戦／準備／ボックスの3タブと新アイコンは一切変更しません。

【受入】Pixel 7a ChromeからURLを開き、タブ往復、在庫→再提案通知、
プレイヤー情報・CSV登録、イベント週切替、戻る操作の一括確認。
注意：週次編成は依然として仮データであり、実ゲーム最適化計算はF1以降です。

【v54起動改善の確認】起動・表示切替・画像表示・オフライン・保存復元・開発初期化をブラウザで再確認。

【v55：短時間読み込みのちらつき抑制】
- 安全な待機オーバーレイは保持し、待機が350msを超えた時だけ「画面を読み込んでいます」を表示。
- 350ms以内の起動／タブ切替では文言を出さない。読み込み完了時と連続タブ切替時は旧タイマーを取消。
- 既存のDOM対話可能時点で表示、画像の遅延読込、3タブ／開発パネルの仕様は維持。

【v56：共通設定ハブ】
- 作戦／準備／ボックスのヘッダー右上に⚙設定を配置。共通モーダルを表示（フッター3タブ維持）。
- プレイヤー情報（鍋容量・バッグ容量・9フィールドボーナス）を設定へ移動。元の保存キーのまま利用でき、移行操作は不要。旧U4単体プレビューは従来フォームを維持。
- ボックス画面は個体検索・個体一覧・CSV/TSV登録に集中。従来のCSV登録は個体追加専用。
- 設定のバックアップ：pokesleep-strategy- で始まるこの作戦室のlocalStorage保存情報だけをJSONでダウンロード。
- 設定の復元：ファイルと件数を確認→確認ダイアログ→作戦室データを置換。重複キー・不正形式・プレイヤー情報・ボックス・イベント選択を検証。失敗時はロールバック、成功後は旧作戦の再保存防止のうえ再起動。
- 他のGitHub PagesアプリのlocalStorageを輸出・削除しません。通常版root index.htmlは変更しません。

【v57：3点ドットメニューへの変更】
- ヘッダー右上の⚙ボタンを廃止し、個体値ぶっこみスキャンに合わせた丸い縦3点「⋮」を配置。
- ⋮をタップすると「プレイヤー情報」「バックアップ・復元」の2項目だけの小メニューが開く。
- メニュー項目を選択すると、その項目だけの専用モーダルを表示。最初の⋮タップでモーダルは開かない。
- メニューは再タップ・外側タップ・Esc・タブ切替で閉じ、古いメニューを残さない。320px幅でも収まる。
- プレイヤー保存内容、既存のJSONバックアップ／復元ロジック、ボックスのCSV登録、3タブ、開発パネル、オフライン対応は維持。

【v58：縦3点ボタンの見た目を簡素化】
- ヘッダーの丸い背景・外枠は撤去し、「⋮」の文字のみ表示。
- タップ領域42×42px、キーボード操作時のフォーカス表示、メニュー／モーダルの開閉動作は維持。
- SWキャッシュを更新し、PWA再起動・オフライン利用時にも最新版へ更新。

【v59：ボックス一覧とヘッダー整理】
- 共通ヘッダーをボックス基準で書式・位置統一。準備の週表示を非表示。
- ボックス先頭に独立した「CSV・TSVから登録」カードと小さな「全削除」ボタン。
- ニックネームと種族名を前方一致検索。ひらがな→カタカナ、半角→全角も正規化。
- 一覧は4列グリッドでレベル／PokeAPI画像＋四角い枠／ニックネーム。100匹以上は「さらに表示」。
- 画像のポケモンIDはsrc/master.jsから検証済みの種族のみ。未登録フォームは誤画像を表示せず代替文字。
- アイコンタップで個体詳細の専用モーダル。個別削除は登録位置と保存スナップショットを照合し、同名個体を誤削除しない。
- 全削除は個体だけを対象に、件数を示す確認を経て実行。プレイヤー・イベント・作戦・他PWAには一切触れない。
- CSV16/17/18列取り込み、バックアップ/復元、⋮の動作、ゲーム計算・開発日時切替は変更しない。
- 実機受入は別ゲート。F1〜F6本計算およびゲーム精度は保留。

【v60：実機フィードバックに基づくBox再調整】
- OK確定：ヘッダー、準備週非表示、最上部の独立CSV/TSVカード、検索、4列Box、個別削除を維持。
- CSV/TSVカードをv58同様の「CSV・TSVから登録」summaryのみのコンパクト折りたたみに復帰。独立カードとして最上部に残す。
- 「全削除」は展開したCSVカードの最下部に格納し、閉じた時は表示しない。削除時の確認とBoxだけの保護は継続。
- ポケモン画像の枠色は作戦タブの色を基準にタイプ別に微調整、背景/境界/下線を同一色系列の落ち着いた色にする。
- Lvとニックネームの画像枠との間隔を2px・同じline-heightに統一。
- 特別衣装「タマザラシ（ホリデー）」はPokeAPIの通常タマザラシ画像(363)に代替。既知衣装だけ明示許可し、リージョンは本来のフォームIDを維持。
